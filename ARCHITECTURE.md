# Правила архитектуры

1. Слои: View — только JSX и вызов `usePresenter`; Presenter берёт данные из хранилища и готовит их; логика — в хуках с понятными именами.
2. Файл — не больше 120 строк. Исключений нет.
3. Дерево папок повторяет иерархию компонентов; у каждого компонента своя папка (view + presenter); вложенность не ограничена.
4. Общие компоненты — в `src/components`; переиспользуемые в одной ветке — в `components` этой ветки; импортируемый один раз в `components` не лежит.
5. `SearchBar/SearchBar.tsx`, `SearchBar/usePresenter.ts`.
6. Архитектура — абстракции, а не инструменты; правила не ослабляем ради скорости.

## Добавлено на практике
7. Инфраструктурные папки `api/`, `store/`, `lib/`, `hooks/` лежат в корне `src` рядом с `components`.
8. Стили — CSS Modules рядом с компонентом (`ShowCard/ShowCard.module.css`).
